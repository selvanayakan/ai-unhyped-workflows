# ai-unhyped-workflows

Tested n8n workflows from the YouTube channel **Selva | AI Unhyped**. Free to use (MIT).

Every workflow here was built and run for a video, with the test data, our raw results and an honest list of what went wrong.

| Workflow | Video | What it does |
|---|---|---|
| [Model Bench: GPT-6 Astra vs Gemini 4 Argon](model-bench-gpt6-vs-argon/) | _link after upload_ | Sends the same tests to two AI models and logs accuracy, speed, tokens and cost |

## How to use a workflow

1. Open its folder and read its README (setup, costs, limits).
2. In n8n: **Workflows → Import from file** → the `.json` file.
3. Add your own API keys. No keys or private links are included here.

Every workflow calls paid APIs with your keys, so check the costs section before running.
